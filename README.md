## 🛠️ Overview

The modern-lakehouse project is a sample setup designed to help you create a modern data lakehouse. With components like MinIO for storage, Nessie for data cataloging, Dremio as your SQL query engine, Apache NiFi for data flows, and Metabase for visualization, you can analyze your data and make informed business decisions.

## 📊 Key Components

- **MinIO**: Functions like an S3 storage service to keep your data safe.
- **Nessie**: Acts as a catalog for your data, helping with data version control.
- **Dremio**: A powerful SQL engine for querying your data effectively.
- **Apache NiFi**: Manages the flow of data during the ETL (Extract, Transform, Load) process.
- **Metabase**: Serves as your dashboard for visualizing data and gaining insights.

## 📋 Features

- **User-Friendly Interface**: Enjoy an easy-to-use graphical interface for managing your data lakehouse.
- **Real-Time Data Processing**: Efficiently handle data with real-time streaming capabilities.
- **Data Visualization**: Create dashboards to visualize your data swiftly.
- **Version Control for Data**: Keep track of data changes and manage versions effortlessly.

## 💡 How to Use

1. **Launch the Application**: Open modern-lakehouse after installation.
2. **Configure Your Storage**: Set up MinIO to manage your data.
3. **Import Data**: Use Apache NiFi to streamline data imports into your lakehouse.
4. **Run Queries**: Leverage Dremio to run SQL queries against your data.
5. **Visualize**: Use Metabase to create visual representations of your data insights.
